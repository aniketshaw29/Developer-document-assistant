# Developer Documentation Assistant

ChatGPT for your codebases. Index documentation from GitHub repos, Swagger/OpenAPI specs, PDFs, and README files — then ask questions in natural language and get answers with source citations.

## Features

- **Multi-source ingestion** — index GitHub repos, Swagger/OpenAPI URLs, PDFs, markdown, and code files
- **RAG-powered answers** — grounded retrieval with per-answer source citations
- **Multi-provider LLM** — OpenAI, Anthropic, or local Ollama, switchable from the UI via LiteLLM
- **Streaming chat** — real-time token streaming over Server-Sent Events
- **Semantic search** — ChromaDB vector store with metadata filtering
- **AST-aware code chunking** — tree-sitter splits code at function/class boundaries

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | FastAPI, Uvicorn |

## Quick Start

### Prerequisites

- Python 3.11+, Node.js 20+, Git
- At least one LLM provider: an OpenAI/Anthropic API key **or** [Ollama](https://ollama.com) running locally

### 1. Backend

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env    # add your API keys
uvicorn app.main:app --reload --port 8000
```

### 2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open **http://localhost:5173** — upload a file or paste a GitHub/Swagger URL, then ask a question.

## Usage

1. **Index docs** — upload markdown/PDF/code files, paste a GitHub repo URL, or provide a Swagger/OpenAPI spec URL
2. **Ask questions** — e.g. "How do I configure Kafka retry?", "Explain Kubernetes Service", "Which endpoint creates orders?"
3. **Get cited answers** — every answer references the exact source chunks used

### API Reference

Interactive docs at **http://localhost:8000/docs** (auto-generated by FastAPI).

| Endpoint | Description |
|---|---|
| `POST /api/v1/chat` | Ask a question, get an answer + sources |
| `POST /api/v1/chat/stream` | Stream tokens via SSE |
| `POST /api/v1/documents/upload` | Upload files (markdown, PDF, code) |
| `POST /api/v1/documents/github` | Index a GitHub repo by URL |
| `POST /api/v1/documents/openapi` | Index a Swagger/OpenAPI spec by URL |
| `GET /api/v1/documents` | List indexed documents |
| `DELETE /api/v1/documents/{id}` | Delete a document |
| `POST /api/v1/search` | Raw semantic retrieval (debugging) |

## Environment Variables

| Variable | Description |
|---|---|
| `OPENAI_API_KEY` | OpenAI key (chat + embeddings) |
| `ANTHROPIC_API_KEY` | Anthropic key (chat) |
| `OLLAMA_BASE_URL` | Ollama base URL, default `http://localhost:11434` |
| `DEFAULT_PROVIDER` | `openai` \| `anthropic` \| `ollama` |
| `DEFAULT_MODEL` | Model name for the default provider |
| `EMBEDDING_MODEL` | Embedding model, default `text-embedding-3-small` |
| `CHROMA_PERSIST_DIR` | ChromaDB storage path, default `./data/chroma` |
| `CORS_ORIGINS` | Allowed frontend origins |
